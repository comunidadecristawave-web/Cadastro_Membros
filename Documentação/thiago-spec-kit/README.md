# 📘 Spec Kit

Guia oficial de padrões, convenções e fluxos de trabalho para documentação de requisitos no repositório **Cadastro Membros**.

Este kit consolida todos os padrões, normas e boas práticas adotadas no projeto, servindo como referência obrigatória para contribuidores.

---

## 📚 Documentos Inclusos

### [FILE_STRUCTURE.md](./FILE_STRUCTURE.md)
Estrutura organizacional do repositório, definindo como as pastas e arquivos devem ser organizados.

**Para:** Entender a hierarquia de pastas, organização de módulos e localização de artefatos.

---

### [GUIDELINES.md](./GUIDELINES.md)
Diretrizes práticas para contribução, incluindo fluxo de trabalho, checklist de validação e boas práticas.

**Para:** Saber como iniciar contribuições, validar antes de commit e seguir o processo correto.

---

### [GIT_WORKFLOW.md](./GIT_WORKFLOW.md)
Padrões e procedimentos Git: branches, commits, pull requests e versionamento.

**Para:** Entender nomenclatura de branches, formato de commits e fluxo de merge.

---

### [NAMING_CONVENTIONS.md](./NAMING_CONVENTIONS.md)
Convenções de nomenclatura para arquivos, pastas, imagens, commits e referências.

**Para:** Nomear corretamente requisitos, imagens, pastas e garantir consistência.

---

### [STANDARDS.md](./STANDARDS.md)
Padrões de escrita, estrutura de seções, versionamento e qualidade documental.

**Para:** Entender como escrever requisitos bem estruturados, seguindo seções obrigatórias.

---

## 🎯 Fluxo de Uso Recomendado

### 1️⃣ **Iniciando uma Contribuição**
1. Consulte [GUIDELINES.md](./GUIDELINES.md) - Fluxo geral
2. Consulte [GIT_WORKFLOW.md](./GIT_WORKFLOW.md) - Criação de branch

### 2️⃣ **Nomeando Arquivos e Pastas**
1. Consulte [NAMING_CONVENTIONS.md](./NAMING_CONVENTIONS.md)
2. Consulte [FILE_STRUCTURE.md](./FILE_STRUCTURE.md) - Localização correta

### 3️⃣ **Escrevendo Requisitos**
1. Consulte [STANDARDS.md](./STANDARDS.md) - Estrutura e seções
2. Selecione e utilize o template mais adequado conforme o tipo de requisito em `.luby/templates/requisitos/`

### 4️⃣ **Finalizando a Contribuição**
1. Consulte [GUIDELINES.md](./GUIDELINES.md) - Checklist de validação
2. Consulte [GIT_WORKFLOW.md](./GIT_WORKFLOW.md) - Commit e PR

---

## ⚠️ Regra de Ouro

**Todos os contribuidores DEVEM ler [GUIDELINES.md](./GUIDELINES.md) antes de iniciar qualquer trabalho.**
